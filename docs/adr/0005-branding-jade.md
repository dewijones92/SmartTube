# 0005. Jade branding everywhere

- Status: Accepted
- Date: 2026-10-31
- Decided by: Dewi (distinctive colour, consistent across icon and app; accepted teal as the default);
  Claude, not separately asked (shifted teal to jade `#10A37F` because upstream's stable build is cyan
  `#0097A7`)

## Decision
All six branding images in `smarttubetv/src/stfocus/res/mipmap-nodpi*` are generated by
`focus/branding/make_icons.py` from upstream's stable S icon: jade badge, 50% dark band, "focus" label.
The red accent colours (`red`, `semi_red`, `light_red`, `dark_red`) are overridden in
`smarttubetv/src/stfocus/res/values/focus.xml`, which turns the search button, progress bars, LIVE badges
and highlights jade.

## Consequences
Re-run `make_icons.py` to change the colour or label; no upstream file is touched.
